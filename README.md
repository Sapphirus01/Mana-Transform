# Mana Transform（魔力转换）

Mana Transform 是一个用于连接 **Dragon Survival（龙之生存）** 与
**Iron's Spells 'n Spellbooks（铁魔法）** 魔力系统的 NeoForge 附属模组。

当当前模组的魔力不足以完成施法时，它会自动使用另一种魔力补足缺口。
这不是一个手动兑换或被动合并魔力池的模组：只有施法需要时才会发生转换。

## 支持版本

当前 `1.0.1` 构建的目标版本为：

| 项目 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.186 及以上、低于 21.2.0 |
| Java | 21 |
| Dragon Survival | 2.0.51 及以上、低于 2.0.67（即 2.0.51～2.0.66） |
| Iron's Spells 'n Spellbooks | 1.21.1-3.15.0 及以上、低于 1.21.1-3.17.0 |

这些范围已经写入模组元数据；范围之外的版本会由 NeoForge 在启动阶段拒绝加载。
Dragon Survival 2.0.63 修改了魔力读取、写入和同步接口，并加入了预留魔力机制。Mana
Transform 1.0.1 会在运行时识别 2.0.51～2.0.62 与 2.0.63～2.0.66 两组接口，并且只把
未预留、可用于施法的龙魔力纳入转换。2.0.66 已使用实际发布 JAR 完成编译和接口检查。
由于本模组会调用两个依赖模组的内部实现并使用 Mixin，尚未验证的 2.0.67 及以后版本
仍可能需要相应更新兼容层，因此暂不提前宣称兼容。

## 安装方法

1. 安装 Minecraft 1.21.1，以及 NeoForge 21.1.186 至 21.1.x 的版本。
2. 安装 Dragon Survival 2.0.51 至 2.0.66；推荐使用当前最新的 2.0.66。
3. 安装 Iron's Spells 'n Spellbooks 1.21.1-3.15.x 或 1.21.1-3.16.x。
4. 根据这两个模组下载页面的要求，安装它们各自的前置模组，例如 Iron's Lib、
   GeckoLib、Curios API 和 Player Animator。不要使用其他 Minecraft 版本的前置。
5. 将 `mana_transform-1.0.1.jar` 放入游戏或服务器的 `mods` 文件夹。
6. 启动游戏，打开“模组”列表，确认三个模组都已成功加载。

联机时，Mana Transform 及其依赖需要同时安装在服务端和所有客户端。发布整合包时，
请把 Dragon Survival 与 Iron's Spells 标记为必需依赖，不要把它们的 JAR 直接打包进
Mana Transform 的 JAR。

## 工作方式

默认转换比例为：

```text
1 点 Dragon Survival 龙魔力 = 50 点 Iron's Spells 铁魔力
```

假设转换比例为 `R`：

- 铁魔法缺少 `X` 点铁魔力时，会消耗 `X ÷ R` 点龙魔力。
- 龙魔法缺少 `Y` 点龙魔力时，会消耗 `Y × R` 点铁魔力。

### 铁魔法的支付顺序

玩家必须是龙，才能用龙魔力补充铁魔力。施展铁魔法时依次使用：

1. Iron's Spells 铁魔力；
2. 不足部分再由 Dragon Survival 龙魔力支付。

### 龙魔法的支付顺序

施展 Dragon Survival 龙魔法时依次使用：

1. Dragon Survival 龙魔力；
2. 龙魔力不足时使用 Iron's Spells 铁魔力；
3. 两种魔力都不足时，最后才沿用 Dragon Survival 原有的经验值魔力规则。

### 持续施法

吐息等持续能力，以及 Iron's Spells 的持续施法也支持转换。为了避免客户端在魔力恰好
归零时先终止施法，模组会在魔力接近耗尽时提前转换一小段缓冲魔力。因此持续施法时，
备用魔力可能在当前魔力条完全归零前开始减少，这是正常行为。

创造模式、无限材料状态或 Dragon Survival 的免费魔力效果仍然遵循原模组规则；不需要
消耗魔力时，Mana Transform 不会额外扣除另一种魔力。

## 配置界面

转换开关和比例由服务器或当前单人世界保存，服务端对实际消耗拥有最终决定权。

1. 先进入一个单人世界或服务器。
2. 按 `Esc`，打开“模组”页面。
3. 在模组列表中选择 **Mana Transform**。
4. 点击“配置”。
5. 使用顶部开关启用或关闭双向魔力转换。
6. 在比例输入框中填写每 1 点龙魔力等价的铁魔力，允许范围为 `1` 至 `1000`。
7. 检查界面显示的正向和反向换算预览。
8. 点击“保存”。新设置会立即同步给在线玩家。

“恢复默认”会把开关设为开启，并将比例恢复为 `50`；仍需点击“保存”才会提交。

### 谁可以修改配置

- 单人世界：世界房主可以修改。
- 专用服务器：需要至少 2 级命令权限，通常需要先由服主执行 `/op 玩家名`。
- 普通玩家：可以查看服务器当前设置，但界面为只读。
- 尚未进入世界时：没有可连接的服务器配置，因此界面为只读。

### 手动修改服务器配置

配置文件位于当前世界目录：

```text
<世界目录>/serverconfig/mana_transform-server.toml
```

主要内容如下：

```toml
[conversion]
enabled = true
ironManaPerDragonMana = 50.0
```

建议关闭对应世界或服务器后再手动编辑，并在修改后重新启动。游戏内配置界面会自动执行
范围检查和同步，通常比直接编辑文件更安全。

## 常见问题

### 有另一种魔力，为什么仍然无法施法？

请依次检查：

- 服务端是否启用了转换；
- 客户端和服务端是否都安装了完全一致的模组版本；
- Dragon Survival 是否处于 2.0.51～2.0.66，Iron's Spells 是否为
  1.21.1-3.15.x 或 1.21.1-3.16.x；
- 使用龙魔力补充铁魔法时，当前玩家是否确实是龙；
- 两个魔力池按当前比例换算后，总量是否真的足够支付完整消耗；
- 是否还有冷却、施法条件、装备、目标或环境限制。Mana Transform 只处理魔力不足，
  不会绕过原模组的其他施法条件。

### 为什么龙魔法最终消耗了经验？

经验值是 Dragon Survival 原有的最后备用来源。Mana Transform 会先尝试龙魔力和铁魔力；
只有两者换算后的可用总量仍不足，或原模组进入其经验支付流程时，才应消耗经验。

### 为什么持续魔法会一次转换一段魔力？

这是防止持续施法在客户端和服务端同步间隙中断的缓冲机制，并非凭空生成魔力。增加到
当前魔力池的数值，应当按照配置比例从另一魔力池扣除。

### 为什么配置按钮不能编辑？

请先进入世界。联机服务器还需要管理员权限；普通玩家只能查看由服务器同步的设置。

### 崩溃提示 Mixin 应用失败怎么办？

这通常意味着 Minecraft、NeoForge、Dragon Survival 或 Iron's Spells 的版本不匹配。
先恢复到“支持版本”表中的组合。如果仍然发生，请保留并提交：

- `logs/latest.log`；
- `crash-reports` 中对应的崩溃报告；
- 客户端和服务端的完整模组列表；
- 能稳定复现问题的施法步骤。

## 服主测试建议

正式开放服务器前，建议至少测试以下场景：

- 龙魔力为零、铁魔力足够时施展一次性龙魔法；
- 铁魔力为零、龙魔力足够时施展一次性铁魔法；
- 龙魔力 → 铁魔力 → 经验值的龙魔法支付顺序；
- 两个方向的持续施法，确认转换扣除和施法不中断；
- 修改比例后，所有在线玩家看到相同结果；
- 非管理员无法修改服务器配置；
- 专用服务器能够正常启动、玩家重连后设置仍然有效。

## 从源码构建

在 Windows PowerShell 中进入项目目录并运行：

```powershell
.\gradlew.bat build
```

构建产物位于：

```text
build/libs/mana_transform-1.0.1.jar
```

开发环境需要 Java 21。依赖由 Gradle 下载，不需要创建 `libs` 文件夹。
